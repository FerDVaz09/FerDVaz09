## 🚀 Proyectos Destacados

### 🤖 [Voice AI Agent – MedCare](https://github.com/FerDVaz09/voice-ai-agent)
Agente de voz inteligente con IA para clínicas médicas. Maneja citas, responde preguntas frecuentes y escala a humanos cuando es necesario.
- **Stack:** Vapi · Llama 3 70B · Groq · FastAPI · PostgreSQL · Docker

---

### 🧪 [Selenium E2E Suite](https://github.com/FerDVaz09/selenium-e2e-suite)
Suite completa de pruebas E2E con patrón POM, reportes Allure y CI/CD automatizado con GitHub Actions.
- **Stack:** Selenium · Pytest · Allure · GitHub Actions

---

### 🔗 [Exterminador de Enlaces Rotos](https://exterminador-enlaces-rotos.onrender.com) · [🚀 Demo Live](https://exterminador-enlaces-rotos.onrender.com)
App web para auditoría automática de enlaces rotos. Detecta 404s, timeouts y códigos HTTP en segundos.
- **Stack:** Python · Flask · BeautifulSoup · Requests

---

### 🛡️ [QA Log Sentinel](https://qa-log-sentinel.onrender.com) · [🚀 Demo Live](https://qa-log-sentinel.onrender.com)
Monitor de logs en tiempo real con interfaz estilo Matrix/Terminal. Polling cada 2s, estadísticas visuales y simulación de eventos.
- **Stack:** Python · Flask · JavaScript · Fetch API

---

### 🎯 [QA Fuzz Master](https://ferdvaz09.github.io/FerDVaz09/projects/qa-fuzz-master.html)
Herramienta de fuzzing para pruebas de seguridad automatizadas: SQL Injection, XSS, Buffer Overflow con screenshots automáticos.
- **Stack:** Python · Flask · Selenium · Faker

---

### 📱 Bot de Soporte WhatsApp + IA
Bot de soporte 24/7 con memoria contextual (RAG), escalamiento automático a humano y sincronización bidireccional con Chatwoot.
- **Impacto:** Automatiza 80%+ de consultas · respuesta en segundos
- **Stack:** Python · Evolution API · Supabase · Redis · OpenAI GPT-4 · Chatwoot

---

### ⚡ Slack App + Thinkific
Automatización de acceso a cursos con comandos `/acceso` y `/fix`. Procesamiento masivo de 700+ usuarios con batch processing.
- **Impacto:** Proceso de 8 horas → 15 minutos
- **Stack:** Python · Slack SDK · Thinkific API · Pandas · Flask
