QAFuzz testing · Seguridad

QA Fuzz Master

Herramienta web que ataca un formulario de login con datos maliciosos y extremos para encontrar fallos de validación, y guarda una captura de cada prueba como evidencia.

PythonFlaskSelenium WebDriverFakerChrome headlessHTML/CSS/JS

En resumen

  • 3 pruebas automáticas por URL
  • Captura de pantalla como evidencia
  • Tabla de resultados por prueba
  • Solo para pruebas autorizadas

El problema

Los formularios de login son una de las primeras puertas de entrada de un ataque. Probar a mano cada caso de entrada maliciosa o excesiva es repetitivo y deja huecos.

La solución

Creé una herramienta que recibe la URL de un sitio con login, abre el formulario en un navegador automatizado y lanza tres tipos de entradas peligrosas. Por cada una guarda una captura y muestra el resultado en una tabla.

Cómo funciona

  1. URL objetivo: se ingresa la dirección de una página con formulario de login.
  2. Navegador automatizado: Selenium abre Chrome en modo headless y localiza los campos de usuario y contraseña.
  3. Inyección SQL: prueba el payload ' OR '1'='1 para intentar saltar la autenticación.
  4. Desbordamiento: envía 500 caracteres aleatorios generados con Faker para probar los límites de validación.
  5. XSS y caracteres especiales: inyecta scripts HTML y emojis para revisar la sanitización.
  6. Evidencia: toma una captura después de cada envío y arma la tabla de resultados.

Características

Inyección SQL

Detecta si el login acepta consultas manipuladas.

Buffer overflow

Revisa qué pasa con entradas mucho más largas de lo esperado.

XSS

Busca falta de sanitización en los campos del formulario.

Evidencia automática

Cada prueba deja una captura lista para el reporte de bug.

Uso educativo y en sistemas con permiso explícito. El código está en un repositorio privado; puedo mostrarlo en una entrevista.
