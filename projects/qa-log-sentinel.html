QA Log Sentinel

Dashboard web que muestra los logs de un servidor en tiempo real, con estilo de terminal, para practicar el análisis de errores durante las pruebas.

PythonFlaskJavaScriptFetch APIHTML/CSSGunicorn

En resumen

  • Actualización automática cada 2 segundos
  • Errores, advertencias e info con colores distintos
  • Contadores en vivo por tipo de log
  • Simulador de tráfico y fallos para practicar

El problema

Cuando pruebas una aplicación, muchos fallos solo se ven en los logs del servidor. Leerlos en un archivo plano es lento y es fácil pasar por alto un error crítico entre cientos de líneas.

La solución

Construí un dashboard que lee el archivo de log del servidor y muestra las últimas entradas en pantalla, separadas por nivel y con contadores. Incluye un panel para generar tráfico normal, advertencias y errores críticos, así se puede practicar cómo detectar y reportar fallos.

Cómo funciona

  1. Servidor Flask: escribe cada evento en un archivo de log con fecha, nivel y mensaje.
  2. Endpoint de lectura: devuelve las últimas 15 líneas del log.
  3. Polling: el navegador consulta ese endpoint cada 2 segundos con Fetch API.
  4. Clasificación: cada línea se pinta según su nivel (ERROR, WARNING, INFO) y se actualizan los contadores.
  5. Panel de control: botones para simular tráfico, fallos críticos con ID único, advertencias y limpiar el log.
2026-10-13 09:41:02 [INFO] Usuario autenticado correctamente
2026-10-13 09:41:04 [WARNING] Uso de CPU alto (87%)
2026-10-13 09:41:06 [ERROR] Fallo crítico en pasarela de pago · ID ERR-4821

Características

Tiempo real

El log se actualiza solo y hace auto-scroll al último evento.

Errores con ID

Cada fallo simulado lleva un identificador único para rastrearlo en un reporte.

Estadísticas

Totales de logs, errores críticos, advertencias y mensajes informativos.

Limpieza segura

Borrar el log pide confirmación antes de hacerlo.
