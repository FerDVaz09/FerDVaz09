Casos seleccionados

Ejemplos de test cases manuales

FailPrueba de volumen

CP-003: procesamiento masivo de usuarios

Precondición: carga preparada de aproximadamente 130 usuarios válidos.

  1. Ejecutar el envío masivo desde el sistema origen.
  2. Esperar confirmación de procesamiento.
  3. Contar usuarios visibles en la plataforma.

Esperado: todos los usuarios se procesan o los fallidos quedan identificados. Actual: solo se visualizan cerca de 20.

FailOAuth / autenticación

CP-MO-001: registro con Google

Precondición: correo de Google nunca registrado.

  1. Abrir pantalla de inicio de sesión.
  2. Presionar Continue with Google.
  3. Seleccionar cuenta nueva y aceptar permisos.

Esperado: sesión creada y dashboard abierto. Actual: Session not found y endpoints de sesión responden 401.

PassPrueba negativa

CP-008: Magic Link inválido o expirado

Precondición: Magic Link vencido o ya usado.

  1. Abrir el enlace inválido.
  2. Validar mensaje y estado de acceso.

Esperado y actual: el sistema muestra un error controlado y no otorga acceso.

FailRegresión / caché

CP-MO-014: insights actualizados

Precondición: existe un análisis antiguo almacenado.

  1. Entrar al módulo de Insights.
  2. Solicitar insights nuevos.
  3. Comparar fecha, contenido y posiciones utilizadas.

Esperado: análisis nuevo. Actual: se conserva un análisis de hace siete meses.

Bug reporting

Defectos documentados con impacto

CríticaAuthentication

BUG-MO-001: Google Sign-In falla para cuentas nuevas

Las cuentas nuevas terminan sin sesión válida luego del callback OAuth.

  • Esperado: usuario creado, sesión establecida y acceso al dashboard.
  • Actual: Session not found, /api/auth/me 401 y broker-mode 401.
  • Impacto: bloquea el registro y acceso de usuarios nuevos.
AltaAPI / data

BUG-002: carga masiva de 130 usuarios solo muestra 20

La integración no deja trazabilidad suficiente para entender usuarios procesados contra faltantes.

  • Esperado: procesamiento completo o fallos individuales identificados.
  • Actual: discrepancia entre enviados y usuarios visibles.
  • Impacto: accesos incompletos para usuarios Pro.
CríticaAI insights

BUG-MO-005: análisis de portafolio obsoleto

El módulo presenta un análisis antiguo como si fuera vigente.

  • Esperado: insight nuevo basado en portafolio actualizado.
  • Actual: análisis de hace siete meses reutilizado.
  • Impacto: riesgo directo sobre decisiones de inversión.
AltaEmail infrastructure

BUG-006: dominio sin validación completa

El dominio estaba configurado solo con sender de soporte, sin validación completa SPF/DKIM/DMARC.

  • Esperado: dominio autenticado para mejorar entregabilidad.
  • Actual: configuración incompleta vinculada a Deferred y correos no recibidos.
  • Impacto: notificaciones críticas no confiables.
